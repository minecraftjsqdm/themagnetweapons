# The Magnet Weapons / 磁性武器

可投掷、可回收的磁力武器：剑、镐、斧、锹、锄与重锤，共 7 个材质档次。

> English version: [README_EN.md](README_EN.md)。

## 内容

- 工具：铁、金、钻石、下界合金、末地陨铁、嫦娥玉石、末世水晶 共 7 档 × 5 类；
  另有一把磁性重锤。
- 投掷：手持工具右键投出，磁力链接保持期间可远程挖掘/攻击；链接中断后按附魔决定是否归还。
- 磁铁：红/蓝两种磁极的陨石磁铁，决定磁极场的吸引与弹射方向。
- 磁极场：同极近距离弹射、异极互相吸引，需至少一方处于吸附态。
- 不稳定区域：投掷工具落点周围形成加速挖掘区域。
- 愚人金矿石：主世界与深板岩两个变种，附带对应掉落物与粗矿。

## 附魔

| ID | 名称 | 效果 |
| --- | --- | --- |
| `themagnetweapons:loyalty` | 忠诚 | 链接中断时立即收回，按等级扣 80 / 60 / 35 点耐久 |
| `themagnetweapons:wriggler` | 蛄蛹者 | 冲刺时贴表面滑行，直到抵达矿镐 |
| `themagnetweapons:stabilizer` | 稳定器 | 稳定模式下投出矿镐不再破坏方块 |
| `themagnetweapons:reach` | 磁距 | 投掷初速 +7%/级 |
| `themagnetweapons:impact` | 震波 | 震波伤害 +10%/级 |
| `themagnetweapons:siphon` | 汲取 | 破坏方块时 3%/级 概率回复 1 点耐久 |
| `themagnetweapons:precision` | 精锐 | 锹可挖掘镐类方块 |
| `themagnetweapons:harvester` | 采掘者 | 镐/斧/锄的掉落直接进入背包 |

## 兼容性说明

- 本模组的「忠诚」是**独立附魔**（`themagnetweapons:loyalty`），
  **不会覆盖**原版 `minecraft:loyalty` 的数据，因此原版三叉戟忠诚不受影响，
  也不会与其他修改附魔数据的模组争抢同一文件。
- 旧做法（用铁砧把原版忠诚书打在磁性工具上）依然有效，代码会同时识别两者并取较高等级。
- 旧命名空间 `themagnetpickaxe` / `magneticweapons` 的物品 ID 在本版本中不再注册，
  从旧版本升级的存档中这些物品会失效，建议先回收或替换。

## 安装

把 `themagnetweapons-1.0.0.jar` 放入 `mods/` 目录即可，客户端与服务端都需要安装。
